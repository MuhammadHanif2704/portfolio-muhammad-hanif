**Peran:** Software Developer Intern (PKL)  
**Periode:** September – Desember 2025  
**Teknologi:** Flutter, Dart, REST API, Postman, Figma, Git/GitHub

**Fitur:**
- Dashboard ringkasan status dan aktivitas pengiriman
- Shipment: pengelolaan data dan status pengiriman
- Manifest: daftar paket per rute/kurir

- Master Data: data kurir, area, dan data pendukung
- Barcode / AWB Scanning: scan resi untuk input dan pelacakan

**Kontribusi:**
- Mengembangkan aplikasi kurir mobile dengan Flutter dan Dart.
- Mengintegrasikan REST API untuk pertukaran data dengan backend.
- Mendesain antarmuka (UI) menggunakan Figma.
- Menguji fitur pada perangkat Android.
- Mengelola kode dengan Git/GitHub.
- Mempresentasikan hasil aplikasi kepada pihak perusahaan sebagai bahan evaluasi.

### 4. Sistem Informasi Pembayaran Listrik Pascabayar

Sistem informasi berbasis web untuk mengelola pembayaran listrik pascabayar.

**Fitur:**

- Pembayaran dan verifikasi pembayaran oleh admin

**Kontribusi:**

- Merancang struktur database 7 tabel beserta relasinya.
- Membuat view, stored procedure, function, trigger, dan transaksi SQL (commit/rollback).
- Mengembangkan logika perhitungan tagihan otomatis.
- Menerapkan autentikasi dan hak akses admin/pelanggan.
- Melakukan debugging dan pengujian blackbox pada fitur utama.
